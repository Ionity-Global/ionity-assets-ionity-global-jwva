## About

**Ionity Assets** (`ionity-assets-ionity-global-jwva`) is the single source of truth for every digital asset belonging to the **Ionity Global** ecosystem.  
It is the place where brand guidelines, design tokens, SVG icons, logos and associated documentation live — versioned, discoverable and ready for integration across all Ionity products.

## Features

- 🎨 **Brand assets** — logos, wordmarks, colour swatches, typography specimens  
- 🔷 **Design tokens** — standardised colour, spacing and typography variables  
- 🖼️ **Icon library** — scalable SVG icons optimised for web and mobile  
- 📐 **Guidelines** — usage rules, clear-space requirements and do/don't examples  
- 📄 **Documentation** — in-repo wiki and published GitHub Pages site  
- 🔒 **MIT licensed** — free to use, attribute and extend

## Getting Started

### View the asset website

Open <https://ionity-global.github.io/ionity-assets-ionity-global-jwva/> in your browser.

### Clone the repository

```bash
git clone https://github.com/Ionity-Global/ionity-assets-ionity-global-jwva.git
cd ionity-assets-ionity-global-jwva
```

### Browse locally

```bash
# No build step required — open docs/index.html directly in a browser
open docs/index.html
```
