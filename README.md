# Ionity Global Digital Assets Repository

This repository contains official Ionity Global media and branding assets used across digital channels, presentations, and promotional material.

## Repository Purpose

Use this repository as the single source for:
- Brand logos and transparent logo variants
- Animated media (GIF/MP4)
- Supporting web assets (CSS/JS/images/favicon)
- Introductory and promotional visual content
- Licensing and policy-related files

## Main Structure

- `/assets/` — primary organized asset library (images, videos, css, js, cookies, favicon, text)
- `/README.md` — repository documentation
- `/LICENSE` and `License-Ionity Global.txt` — licensing information

## Usage Guidelines

1. Use original files without renaming unless required by a delivery target.
2. Prefer optimized assets when available for web publishing.
3. Keep new files grouped by media type inside `/assets/`.
4. Retain existing transparent and high-resolution variants for design workflows.

## Asset Types Included

- **Logos:** PNG transparent and optimized versions  
- **Graphics:** Brand images and banners  
- **Animation:** GIF files for digital use  
- **Video:** MP4 intro/promo content  
- **Web Support Files:** Cookie banner HTML, CSS, JS, favicon assets  

## Licensing

Please review:
- `LICENSE`
- `License-Ionity Global.txt`
- `/assets/Lisences,Policy,EULA/` (repository folder name; contains policy/EULA-related files)

## Notes

- This repository is asset-focused and does not include an application build/test workflow.
- Keep file naming consistent and avoid committing temporary design exports.
