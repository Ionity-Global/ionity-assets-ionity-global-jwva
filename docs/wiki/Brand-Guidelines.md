# Brand Guidelines — Ionity Global

> **Maintained by** Johan Wilhelm van Antwerp (JWVA) / *Antwerp Ecosystems Designs Ionity ÆĐï*

This page describes how to correctly use the **Ionity Global** brand assets.

---

## Logo Usage

| Variant | When to use |
|---|---|
| Primary (light background) | Default usage on white or light surfaces |
| Reversed (dark background) | On dark or coloured backgrounds |
| Monochrome | Single-colour print, embossing, watermarking |
| Icon-only | App icons, favicons, small contexts |

### Clear Space

Always maintain a minimum clear space equal to **half the logo height** on all sides.

### Minimum Size

- Digital: **32 px** minimum height
- Print: **10 mm** minimum height

### Do ✅

- Use approved colour variants only
- Maintain aspect ratio at all times
- Use vector (SVG/PDF) files whenever possible

### Don't ❌

- Do not stretch, skew or rotate the logo
- Do not add drop shadows or other effects
- Do not place on busy or low-contrast backgrounds
- Do not recolour outside approved palette

## Colour Palette

| Name | Hex | Usage |
|---|---|---|
| Ionity Amber | `#F5A623` | Primary accent, CTAs, highlights |
| Ionity Black | `#0D0D0D` | Backgrounds (dark theme) |
| Ionity Surface | `#1A1A1A` | Card / panel backgrounds |
| Ionity White | `#E8E8E8` | Body text on dark backgrounds |
| Ionity Muted | `#888888` | Secondary text, captions |

---

## Typography

| Role | Typeface | Weight |
|---|---|---|
| Headings | Segoe UI / system-ui | 700 (Bold) |
| Body | Segoe UI / system-ui | 400 (Regular) |
| Code / Mono | Fira Code / Cascadia Code | 400 |

---

## File Formats

| Format | Use case |
|---|---|
| `.svg` | Web, scalable digital use |
| `.png` | Raster digital use (provide @1x, @2x, @3x) |
| `.pdf` | Print-ready vector |
