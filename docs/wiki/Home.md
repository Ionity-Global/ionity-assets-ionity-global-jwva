## What is Ionity Assets?

**Ionity Assets** is the single source of truth for every digital asset
belonging to the **Ionity Global** ecosystem. It provides:

- 🎨 Brand assets (logos, wordmarks, colour swatches, typography)
- 🔷 Design tokens (colours, spacing, typography variables)
- 🖼️ SVG icon library
- 📐 Brand guidelines (usage rules, clear-space, do/don't)
- 📄 Documentation (this wiki + published GitHub Pages site)
